## AI Tools Used

I used **ChatGPT** as an AI assistant during the development of this project.

## How AI Was Used

AI was used for:

- Understanding the assignment requirements and planning the API structure.
- Getting suggestions for Express.js project organization.
- Generating initial ideas for API routes and test cases.
- Reviewing possible edge cases for expense creation, filtering, total calculation, and deletion.
- Helping debug issues while writing Jest and Supertest API tests.

## AI-Generated vs Developer-Written Code

### AI-generated assistance

- Initial suggestions for Express API structure.
- Test case ideas using Jest and Supertest.
- Suggestions for handling validation and API responses.

### Written and implemented by me

- Final project structure.
- Express routes and application logic.
- Expense data handling.
- API validation rules.
- Test integration and configuration.
- Final changes required to make the application work correctly.

## Validation and Changes Made

I reviewed and tested all AI suggestions before using them.

### Changes I made after reviewing AI output

- Adjusted API routes according to my implementation.
- Modified test cases to match my actual endpoint behavior.
- Verified HTTP status codes and response formats.
- Tested all endpoints manually and through automated tests.
- Removed unnecessary suggestions that did not fit the project requirements.

## AI Suggestions Not Used

Some AI suggestions were not included because:

- They added unnecessary complexity for this assignment.
- A database implementation was not required, so I kept data storage simple.
- Additional libraries were avoided unless they provided clear value.
